## 🚀 Quick Start

```bash
# Backend
cd backend
npm install
npm start

# Frontend (new terminal)
cd frontend
npm install
npm run dev
```

---

## 📊 Key Statistics

- **Backend**: Node.js + Express.js + Firebase Firestore
- **Frontend**: React.js + Vite + Tailwind CSS
- **Database**: Firebase Firestore (51 books seeded)
- **Authentication**: JWT + bcryptjs
- **API Endpoints**: 15+ protected and public routes
